# Industrial Sensor Monitor

> **پلتفرم:** Windows 10 / 11 — 64 bit
> **فریم‌ورک:** .NET 10 (`net10.0-windows`)

## ۱. معرفی نرم‌افزار

**Industrial Sensor Monitor** یک برنامه ویندوزی سبک برای ثبت و مشاهده اطلاعات سنسورهای صنعتی است.

کاربر نوع سنسور را از فهرست انتخاب می‌کند، مقدار اندازه‌گیری‌شده را وارد می‌کند و واحد اندازه‌گیری را (که به‌صورت خودکار پیشنهاد می‌شود) تأیید یا تغییر می‌دهد. با زدن دکمه «ثبت اطلاعات»:

- رکورد به فایل **`sensors.json`** اضافه می‌شود (بدون هیچ سرور یا دیتابیسی).
- تاریخ و ساعت ثبت در همان لحظه توسط برنامه ثبت می‌شود.
- جدول اطلاعات بلافاصله به‌روزرسانی می‌شود و جدیدترین رکورد در بالاترین ردیف قرار می‌گیرد.

اطلاعات روی دیسک ذخیره می‌شوند و با بستن یا اجرای مجدد برنامه **از بین نمی‌روند**.

> این نسخه برای اجرا و نمایش (دمو و تمرین) طراحی شده است: کافی است فایل `IndustrialSensorMonitor.exe` را اجرا کنید. **نه SQL Server لازم است، نه نصب دیتابیس، نه تنظیم Connection String.**

## ۲. امکانات اصلی برنامه

- انتخاب نوع سنسور از ComboBox (دما، فشار، رطوبت، سرعت)
- نمایش خودکار واحد پیش‌فرض هر سنسور و امکان ویرایش آن
- ورود مقدار عددی صحیح یا اعشاری با **چهار رقم اعشار**، پشتیبانی از مقادیر منفی و مقدار صفر
- ذخیره مقدار به‌صورت `decimal` (بدون تبدیل به `double`/`float`) تا دقت اعشار از بین نرود
- ذخیره‌سازی در فایل JSON محلی با نوشتن اتمیک (نوشتن در فایل موقت و سپس جایگزینی)
- ذخیره متن فارسی به‌صورت خوانا در فایل (بدون `\u06XX`)
- نمایش اطلاعات در `DataGridView` به‌صورت فقط‌خواندنی، راست‌چین و فارسی
- مرتب‌سازی نزولی بر اساس تاریخ ثبت (جدیدترین رکورد در ابتدا)
- پاک‌سازی خودکار ورودی‌ها پس از ثبت موفق و آماده‌سازی فرم برای ثبت بعدی
- اعتبارسنجی کامل ورودی‌ها پیش از ذخیره‌سازی
- نمایش وضعیت ذخیره‌سازی و تعداد رکوردها در سربرگ فرم
- دکمه **«پوشه داده»** برای باز کردن محل فایل JSON در Windows Explorer
- ساخت خودکار فایل داده همراه با **۱۰ رکورد نمونه** در اولین اجرا
- بازسازی خودکار فایل در صورت خرابی محتوا (با گرفتن نسخه پشتیبان)
- مدیریت خطاها با پیام‌های فارسی و ثبت جزئیات فنی در فایل گزارش
- رابط کاربری فارسی، راست‌چین و مقیاس‌پذیر در رزولوشن‌های مختلف ویندوز
- نسخه اجرایی مستقل (Self-contained Single File) بدون نیاز به نصب .NET Runtime
- بسته نصبی ویندوز (Inno Setup) با میانبر Desktop و Start Menu و Uninstall استاندارد
- نسخه قابل حمل (Portable ZIP)
- ساخت خودکار نسخه‌ها با GitHub Actions و انتشار در GitHub Releases

**امکانات افزوده‌شده در نسخه ۱٫۲٫۰:**

- نمایش **تاریخ شمسی** در جدول (تقویم هجری خورشیدی، ساعت ۲۴ ساعته)
- **ویرایش** و **حذف** رکورد با تأییدیه (دکمه، منو، کلید `F2` و `Delete` و دوبار کلیک)
- **جست‌وجو و فیلتر** بر اساس نوع سنسور، متن، بازه مقدار و بازه تاریخ (با پشتیبانی از ارقام فارسی)
- **خروجی CSV** سازگار با Excel (UTF-8 با BOM) و **ورود از CSV** با گزارش خطوط نامعتبر
- **آستانه هشدار** برای هر سنسور و رنگ‌بندی قرمز رکوردهای خارج از محدوده
- **پایش زنده شبیه‌سازی‌شده** (تایمر ۲ ثانیه‌ای) برای نمایش ثبت خودکار داده
- **نمودار خطی** آخرین ۲۴ مقدار سنسور انتخاب‌شده (بدون کتابخانه گرافیکی جانبی)
- **نسخه‌های پشتیبان چرخشی** (۱۰ نسخه آخر) در پوشه `Backups`
- پنجره **«درباره برنامه»** و **نوار وضعیت** (نسخه، مسیر فایل، تعداد رکورد)
- بررسی **نسخه جدید** از GitHub Releases و آیکون اختصاصی برنامه

## ۳. تکنولوژی‌های استفاده‌شده

| بخش | تکنولوژی |
|---|---|
| زبان برنامه‌نویسی | C# |
| رابط کاربری | Windows Forms |
| پلتفرم | Windows Desktop |
| فریم‌ورک | .NET 10 (`net10.0-windows`) |
| ذخیره‌سازی | فایل JSON محلی با `System.Text.Json` |
| خواندن تنظیمات | `Microsoft.Extensions.Configuration` + `Microsoft.Extensions.Configuration.Json` |
| ثبت گزارش | فایل متنی در `%LOCALAPPDATA%` |
| ساخت Installer | Inno Setup 6 |
| Build و انتشار | .NET CLI + GitHub Actions |

**پکیج‌های NuGet (نسخه‌ها در فایل csproj مشخص شده‌اند):**

```xml
<PackageReference Include="Microsoft.Extensions.Configuration" Version="10.0.0" />
<PackageReference Include="Microsoft.Extensions.Configuration.Json" Version="10.0.0" />
```

کتابخانه `System.Text.Json` بخشی از خود .NET است و نیازی به پکیج جداگانه ندارد. هیچ ORM، هیچ کتابخانه گرافیکی شخص ثالث و هیچ وابستگی به SQL Server وجود ندارد.

## ۵. محل ذخیره اطلاعات

اطلاعات در یک فایل JSON به نام `sensors.json` ذخیره می‌شود. مسیر پیش‌فرض:

```text
%LOCALAPPDATA%\IndustrialSensorMonitor\Data\sensors.json
```

در ویندوز ۱۰/۱۱ معمولاً معادل مسیر زیر است:

```text
C:\Users\<نام کاربری>\AppData\Local\IndustrialSensorMonitor\Data\sensors.json
```

**چند نکته:**

- فایل داده **بیرون از مسیر نصب برنامه** است؛ بنابراین حذف/Uninstall برنامه باعث پاک شدن اطلاعات نمی‌شود.
- برای پیدا کردن سریع فایل، در برنامه دکمه **«پوشه داده»** را بزنید تا Explorer روی همان فایل باز شود.
- مسیر فایل را می‌توانید در فایل `appsettings.json` (کنار فایل اجرایی) تغییر دهید:

```json
{
  "Storage": {
    "DataFilePath": "D:\\SensorData\\sensors.json"
  }
}
```

- اگر مقدار `DataFilePath` خالی باشد، مسیر پیش‌فرض بالا استفاده می‌شود.
- مسیر نسبی (مثل `"sensors.json"`) نسبت به پوشه فایل اجرایی محاسبه می‌شود؛ برای نسخه Portable می‌توانید از این حالت استفاده کنید تا داده کنار خود برنامه ذخیره شود.
- متغیرهای محیطی مثل `%USERPROFILE%` در مسیر پشتیبانی می‌شوند.
- پس از تغییر `appsettings.json`، برنامه را دوباره اجرا کنید.

## ۶. ساختار فایل JSON

نمونه محتوای فایل `sensors.json`:

```json
{
  "version": 1,
  "nextId": 11,
  "sensors": [
    {
      "id": 1,
      "sensorName": "سنسور دما",
      "value": 21.75,
      "unit": "°C",
      "recordDate": "2026-11-02T10:15:30.1234567+03:30"
    },
    {
      "id": 2,
      "sensorName": "سنسور رطوبت",
      "value": 43.5,
      "unit": "%",
      "recordDate": "2026-11-02T13:15:30.1234567+03:30"
    }
  ]
}
```

| کلید | توضیح |
|---|---|
| `version` | نسخه ساختار فایل (برای سازگاری نسخه‌های بعدی) |
| `nextId` | شناسه‌ای که به رکورد بعدی داده می‌شود |
| `sensors` | آرایه رکوردهای سنسور |
| `id` | شناسه یکتای رکورد (به‌صورت خودکار افزایش می‌یابد) |
| `sensorName` | نام سنسور (متن فارسی) |
| `value` | مقدار سنسور (عدد؛ دقت چهار رقم اعشار حفظ می‌شود) |
| `unit` | واحد اندازه‌گیری |
| `recordDate` | تاریخ و ساعت ثبت به قالب ISO 8601 با ساعت محلی سیستم |

## ۷. داده‌های نمونه اولین اجرا

اگر فایل `sensors.json` وجود نداشته باشد (اولین اجرای برنامه)، به‌صورت خودکار ساخته می‌شود و **۱۰ رکورد نمونه** در آن نوشته می‌شود تا برنامه از همان ابتدا جدول پُر داشته باشد:

| شناسه | سنسور | مقدار | واحد |
|---|---|---|---|
| 1 | سنسور دما | 21.75 | °C |
| 2 | سنسور رطوبت | 43.5 | % |
| 3 | سنسور فشار | 1.0132 | bar |
| 4 | سنسور سرعت | 8.4 | m/s |
| 5 | سنسور دما | 67.2 | °C |
| 6 | سنسور رطوبت | 31.4 | % |
| 7 | سنسور فشار | 4.756 | bar |
| 8 | سنسور سرعت | 0 | m/s |
| 9 | سنسور دما | -3.25 | °C |
| 10 | سنسور رطوبت | 78.65 | % |

این رکوردها فقط یک بار (هنگام ساخت فایل) اضافه می‌شوند و در اجراهای بعدی تکرار نمی‌شوند.

## ۸. ویرایش دستی فایل داده

چون داده‌ها در یک فایل متنی ساده هستند، می‌توانید آن را با Notepad یا VS Code باز و ویرایش کنید:

1. دکمه **«پوشه داده»** را بزنید (یا مسیر بخش ۵ را باز کنید).
2. فایل `sensors.json` را با Notepad باز کنید.
3. رکورد جدید را به آرایه `sensors` اضافه کنید و مقدار `nextId` را یک عدد بیشتر کنید.
4. فایل را با کدگذاری **UTF-8** ذخیره کنید.
5. در برنامه دکمه **«به‌روزرسانی لیست»** را بزنید تا تغییرات نمایش داده شوند.

**قواعد مهم:**

- ساختار JSON باید معتبر باشد (ویرگول‌ها، آکولادها و براکت‌ها).
- مقدار `value` را بدون گیومه و با نقطه اعشار بنویسید: `36.5`
- مقدار `recordDate` را به قالب `yyyy-MM-ddTHH:mm:ss` بنویسید.
- فایل با برنامه دیگری (مثلاً Excel) همزمان باز نباشد.

## ۹. پشتیبان‌گیری و بازیابی

**پشتیبان‌گیری خودکار (نسخه ۱٫۲٫۰):** پیش از هر ذخیره‌سازی (ثبت، ویرایش، حذف یا ورود گروهی)، برنامه یک نسخه از فایل
فعلی را در پوشه `Backups` کنار فایل داده با نام `sensors-YYYYMMDD-HHmmss-fff.json` ذخیره می‌کند و فقط **۱۰ نسخه آخر** را
نگهداری می‌کند. مسیر کامل این پوشه در پنجره «درباره برنامه» نمایش داده می‌شود.

**پشتیبان‌گیری دستی:** کافی است از فایل `sensors.json` یک کپی بگیرید (مثلاً `sensors-backup.json`).

**اگر فایل خراب شود:**

- اگر محتوای فایل JSON نامعتبر باشد (مثلاً ویرایش دستی اشتباه)، برنامه هنگام اجرا فایل خراب را با نام
  `sensors.broken-YYYYMMDD-HHmmss.json` در همان پوشه نگه می‌دارد و یک فایل تازه همراه با داده‌های نمونه می‌سازد؛
  سپس پیام اطلاعاتی نمایش می‌دهد. این‌گونه هیچ داده‌ای بی‌بازگشت از بین نمی‌رود و برنامه هم قفل نمی‌شود.
- برای بازیابی، فایل پشتیبان را با نام `sensors.json` جایگزین کنید و برنامه را دوباره اجرا کنید.

**اگر مسیر فایل قابل نوشتن نباشد** (مثلاً مسیر درایو readonly)، برنامه پیام فارسی مناسب نمایش می‌دهد و در فایل گزارش
(`%LOCALAPPDATA%\IndustrialSensorMonitor\Logs`) جزئیات را ثبت می‌کند.

## ۱۰. نحوه باز کردن پروژه در Visual Studio

1. Visual Studio سازگار با **.NET 10** را نصب کنید (workload **.NET Desktop Development** لازم است).
2. فایل `IndustrialSensorMonitor.sln` را از ریشه مخزن باز کنید.
3. Visual Studio دو پروژه را نشان می‌دهد:
   - `IndustrialSensorMonitor` (پروژه اصلی Windows Forms)
   - `IndustrialSensorMonitor.Tests` (پروژه تست با xUnit)
4. پروژه `IndustrialSensorMonitor` را به‌عنوان Startup Project تنظیم کنید.
5. کلید `F5` را بزنید؛ فرم اصلی برنامه باز می‌شود.

پکیج‌های NuGet در اولین Build به‌صورت خودکار Restore می‌شوند.

## ۱۱. نحوه نصب پکیج‌های NuGet

نسخه پکیج‌ها در فایل `src/IndustrialSensorMonitor/IndustrialSensorMonitor.csproj` ثابت شده است، بنابراین:

```powershell
dotnet restore
```

یا در Visual Studio: راست‌کلیک روی Solution → **Restore NuGet Packages**.

## ۱۲. نحوه Build کردن پروژه

از ریشه مخزن:

```powershell
# بازیابی پکیج‌ها
dotnet restore IndustrialSensorMonitor.sln

# ساخت نسخه Debug
dotnet build IndustrialSensorMonitor.sln -c Debug

# ساخت نسخه Release
dotnet build IndustrialSensorMonitor.sln -c Release
```

خروجی Build در مسیر `src/IndustrialSensorMonitor/bin/Release/net10.0-windows/` قرار می‌گیرد و برای اجرا باید فایل
`appsettings.json` نیز کنار آن باشد (این فایل به‌صورت خودکار کپی می‌شود).

dotnet test tests/IndustrialSensorMonitor.Tests/IndustrialSensorMonitor.Tests.csproj -c Release

| فایل تست | موضوع |

## ۱۶. نحوه اجرای GitHub Actions

Workflow در مسیر `.github/workflows/build-release.yml` قرار دارد و با رویدادهای زیر اجرا می‌شود:

| رویداد | توضیح |
|---|---|
| `push` به شاخه `main` (و `test`) | ساخت خودکار نسخه در هر Push |
| `pull_request` به `main`/`test` | اجرای Build، تست‌ها و پوشش کد روی هر Pull Request |
| `workflow_dispatch` | اجرای دستی از صفحه Actions |
| `push` تگ `v*` | ساخت نسخه + ایجاد GitHub Release |

**اجرای دستی:**

1. وارد مخزن در GitHub شوید.
2. تب **Actions** را باز کنید.
3. از ستون سمت چپ، workflow با نام **Build and Release** را انتخاب کنید.
4. دکمه **Run workflow** را بزنید، شاخه موردنظر را انتخاب و تأیید کنید.

**مراحل Workflow:**

1. آماده‌سازی Windows Runner و نصب .NET SDK 10
2. `dotnet restore` و `dotnet build` در حالت Release
3. اجرای تست‌ها (در صورت شکست، انتشار متوقف می‌شود)
4. `dotnet publish` با تنظیمات Self-contained + Single File (win-x64)
5. نصب Inno Setup و ساخت `IndustrialSensorMonitor-Setup-x64.exe`
6. ساخت `IndustrialSensorMonitor-Portable-x64.zip`
7. بارگذاری سه Artifact جداگانه
8. در صورت اجرا با Tag، ساخت GitHub Release و پیوست فایل‌ها

**انتشار نسخه جدید با Tag:**

```bash
git tag v1.3.0
git push origin v1.3.0
```

## ۱۹. نحوه نصب و حذف نرم‌افزار

**نصب:**

1. `IndustrialSensorMonitor-Setup-x64.exe` را اجرا کنید.
2. مسیر نصب را (در صورت نیاز) تغییر دهید و **Next** را بزنید.
3. نصب را کامل کنید؛ میانبرها ساخته می‌شوند.
4. برنامه را اجرا کنید؛ در اولین اجرا فایل داده همراه با ۱۰ رکورد نمونه ساخته می‌شود.

**نسخه Portable:**

فایل ZIP را در هر مسیری استخراج کنید و `IndustrialSensorMonitor.exe` را اجرا کنید. اگر می‌خواهید فایل داده کنار خود
برنامه باشد، در `appsettings.json` مقدار زیر را قرار دهید:

```json
{ "Storage": { "DataFilePath": "sensors.json" } }
```

**حذف:**

- از **Settings → Apps → Installed apps** گزینه `Industrial Sensor Monitor` را انتخاب و **Uninstall** کنید، یا
- از **Control Panel → Programs and Features** حذف کنید، یا
- فایل `unins000.exe` را در مسیر نصب اجرا کنید.

| مورد | نتیجه |
|---|---|
| فایل‌های اجرایی برنامه | حذف می‌شوند |
| میانبرهای Desktop و Start Menu | حذف می‌شوند |
| فایل داده `sensors.json` و اطلاعات ثبت‌شده | **باقی می‌مانند** |

اگر می‌خواهید اطلاعات را هم پاک کنید، فایل `%LOCALAPPDATA%\IndustrialSensorMonitor\Data\sensors.json` را
به‌صورت آگاهانه و دستی حذف کنید.

## ۲۳. قابلیت‌های نسخه ۱٫۲٫۰

### الف) تاریخ شمسی، آیکون، درباره و پشتیبان‌گیری

- ستون «تاریخ و ساعت ثبت» با تقویم هجری خورشیدی نمایش داده می‌شود (`1405/08/13 10:22:33`)؛ داده‌ها همچنان به‌صورت
  تاریخ استاندارد در فایل JSON ذخیره می‌شوند و نمایش آن‌ها شمسی است.
- آیکون برنامه در فایل اجرایی، میان‌بر ویندوز و فایل نصب استفاده می‌شود.
- پنجره **«درباره برنامه»** (منوی «راهنما» یا کلید `F1` یا دکمه «درباره») نسخه، محل فایل داده، مسیر نسخه‌های پشتیبان و
  دکمه بررسی نسخه جدید را نشان می‌دهد.
- **نوار وضعیت** پایین پنجره: پیام وضعیت، تعداد رکوردها، مسیر فایل داده و شماره نسخه.

### ب) ویرایش، حذف، جست‌وجو و CSV

| کار | راه‌های انجام |
|---|---|
| ویرایش رکورد | دکمه «ویرایش رکورد»، منوی «رکوردها»، کلید `F2` یا دوبار کلیک روی ردیف |
| حذف رکورد | دکمه «حذف رکورد»، منوی «رکوردها» یا کلید `Delete` (همراه با تأییدیه) |
| خروجی CSV | دکمه «خروجی CSV» یا `Ctrl+E` |
| ورود از CSV | دکمه «ورود از CSV» یا منوی «فایل» |
| اعمال فیلتر | دکمه «اعمال فیلتر» یا کلید `Enter` در کادرهای فیلتر |

- فیلترها: نوع سنسور، متن آزاد (نام/واحد/شناسه/مقدار)، بازه مقدار و بازه تاریخ. هر کادر که خالی بماند اعمال نمی‌شود.
- ورودی‌های عددی فیلتر، ارقام فارسی (۱۲۳) و جداکننده اعشار فارسی (٫) را هم می‌پذیرند.
- فایل CSV با **UTF-8 + BOM** ذخیره می‌شود تا متن فارسی در Excel درست نمایش داده شود و شامل هر دو ستون تاریخ شمسی و
  میلادی است. ورود اطلاعات، ستون تاریخ میلادی (یا شمسی در صورت نبود) را می‌خواند و خطوط نامعتبر را با شماره خط گزارش می‌کند.
- خروجی CSV شامل همان رکوردهایی است که در جدول **نمایش داده می‌شوند** (یعنی فیلتر فعلی روی خروجی اثر دارد).

### ج) آستانه هشدار، پایش زنده و نمودار

| سنسور | واحد | محدوده معمول |
|---|---|---|
| سنسور دما | °C | −۵۰ تا ۱۵۰ |
| سنسور فشار | bar | ۰ تا ۱۰ |
| سنسور رطوبت | % | ۰ تا ۱۰۰ |
| سنسور سرعت | m/s | ۰ تا ۵۰ |

- مقدارهای خارج از این محدوده در جدول با **پس‌زمینه قرمز** نمایش داده می‌شوند و هنگام ثبت/ویرایش، پیام تأیید نمایش داده می‌شود.
- **پایش زنده:** منوی «پایش» → «شروع پایش زنده». هر ۲ ثانیه یک قرائت شبیه‌سازی‌شده از یکی از سنسورها ساخته و ثبت می‌شود.
  با «توقف پایش زنده» متوقف می‌شود و با بستن پنجره هم به‌صورت خودکار خاموش می‌شود. این داده‌ها **واقعی نیستند**.
- **نمودار:** مقادیر سنسور(های) انتخاب‌شده را با GDI+ و بدون کتابخانه جانبی رسم می‌کند؛ با تیک
  «نمایش نمودار» می‌توان آن را پنهان کرد. جزئیات نمودار حرفه‌ای در نسخه ۱٫۳٫۰ آمده است.

### د) مهندسی و CI

- بررسی نسخه جدید با `GET https://api.github.com/repos/hoseinsedaqat/Industrial-SensorMonitor/releases/latest`
  (بدون نیاز به توکن؛ در صورت نبود اینترنت پیام فارسی نمایش داده می‌شود و برنامه ادامه می‌دهد).
- Workflow: کش پکیج‌های NuGet، اجرای `dotnet format --verify-no-changes` (غیرمسدودکننده، با گزارش در Artifact)،
  خلاصه نتایج تست‌ها در صفحه اجرا و بارگذاری گزارش قالب‌بندی.
- فایل‌های `CHANGELOG.md`، `LICENSE` (MIT)، `.editorconfig`، `Directory.Build.props` و `dependabot.yml`.

## ۲۴. قابلیت‌های نسخه ۱٫۳٫۰

### الف) بازطراحی ظاهر

- تم روشن با پالت متمرکز در `UI/AppTheme.cs` (پس‌زمینه، سطح، حاشیه، رنگ تأکیدی، رنگ‌های وضعیت) و فونت `Tahoma`.
- سربرگ گرادیانی (`UI/HeaderBand.cs`) شامل عنوان، زیرعنوان، نشان نسخه و «قرص وضعیت» رنگی.
- کارت‌های گوشه‌گرد (`UI/CardPanel.cs`) با سایه ملایم، خط تأکید رنگی، عنوان راست‌چین و راهنمای کوچک.
- دکمه‌های سفارشی (`UI/AccentButton.cs`) با انواع Primary/Secondary/Danger/Success/Ghost و آیکون برداری (`UI/VectorIcons.cs`).
- جدول با سرستون خوانا، ردیف‌های یک‌درمیان و رنگ‌بندی سه‌سطحی (عادی/هشدار/بحرانی).
- هیچ فایل تصویری و هیچ کتابخانه گرافیکی جانبی استفاده نشده است.

### ب) پایداری داده

- اجرای تک‌نسخه‌ای با `Mutex` (پیام فارسی در صورت اجرای هم‌زمان).
- **نسخه‌های پشتیبان** (دکمه «نسخه‌های پشتیبان» یا منوی «فایل») با فهرست تاریخ شمسی، تعداد رکورد و حجم، و بازگردانی امن.
- **سلامت داده** (دکمه «سلامت داده» یا منوی «فایل»): حذف رکوردهای نامعتبر و بازسازی فایل.
- گزارش‌های قدیمی‌تر از ۳۰ روز در شروع برنامه پاک می‌شوند.

### ج) تجربه جدول

| کار | راه انجام |
|---|---|
| مرتب‌سازی | کلیک روی سرستون (کلیک دوباره جهت را برمی‌گرداند) |
| فیلتر خودکار | تایپ در کادر جست‌وجو (اعمال پس از ۳۵۰ میلی‌ثانیه) |
| حذف گروهی | انتخاب چند ردیف با `Ctrl` و سپس `Delete` |
| بازگردانی حذف | دکمه «بازگردانی حذف» یا `Ctrl+Z` |
| پرش به جست‌وجو | `Ctrl+F` |
| ویرایش سریع | `F2` یا دوبار کلیک |

- اندازه و وضعیت پنجره و تنظیمات نمودار در `%LOCALAPPDATA%\IndustrialSensorMonitor\settings.json` ذخیره می‌شود.

### د) تحلیل

- بازه زمانی نمودار: ۲۴ ساعت، ۷ روز، ۳۰ روز و همه رکوردها.
- نمایش هم‌زمان تا چهار سنسور در یک نمودار (با فیلتر «همه سنسورها» یا انتخاب چند ردیف).
- ذخیره تصویر نمودار به‌صورت PNG.
- **گزارش هشدارها**: فهرست رکوردهای هشدار/بحرانی با توضیح فارسی و خروجی CSV.

### و) نمودار و نمایش حرفه‌ای داده

- نوار سبز **محدوده معمول سنسور** روی نمودار (فقط در حالت تک‌سری) تا مقدارهای عادی و خارج از محدوده از هم جدا شوند.
- خط نرم با **گرادیان زیر خط**، نقاط سفید-توپر و رنگ قرمز برای مقدارهای خارج از محدوده هر سنسور.
- **راهنمای رنگی** بالای نمودار با نام سنسور و آخرین مقدار، و برچسب واحد روی محور عمودی.
- **حرکت ماوس روی نمودار**: خط راهنمای عمودی و کادر مقدار با نام سنسور، مقدار دقیق و تاریخ شمسی.
- سه برچسب تاریخ روی محور افقی (شروع، میانه، پایان) و پیام راهنما در حالت بدون داده.
- جدول داده‌ها: **نوار رنگی هشدار** در لبه هر ردیف، مقدار برجسته برای ردیف‌های هشدار، **برجسته‌سازی ردیف زیر ماوس**
  و پیام حالت خالی («هنوز رکوردی ثبت نشده است» / «رکوردی مطابق فیلتر پیدا نشد»).
- نوار ابزار جدول، تعداد ردیف‌های انتخاب‌شده و راهنمای عملیات گروهی را نشان می‌دهد.

### ه) مهندسی و CI

- `Directory.Packages.props` (مدیریت متمرکز نسخه پکیج‌ها) و `global.json` (قفل نسخه SDK).
- بررسی خودکار یکسان بودن شماره نسخه در `csproj`، `Setup.iss`، `CHANGELOG.md` و Tag.
- یادداشت‌های GitHub Release به‌صورت خودکار از `CHANGELOG.md` ساخته می‌شود.
- تست روی Pull Request + پوشش کد با `coverlet.collector` (خروجی در Artifact `coverage`).
- `.gitattributes` برای یکسان‌سازی پایان خط.

## پیوست: گزارش خطاها و رفع اشکال

**محل فایل گزارش:** `%LOCALAPPDATA%\IndustrialSensorMonitor\Logs\app-YYYYMMDD.log`

| پیام / نشانه | علت | راه‌حل |
|---|---|---|
